# 从 AI 生成策略到回测：新手操作指南

这份教程写给第一次接触 OKX Trading 的用户：你可以不会写 Java，但需要先把交易规则讲清楚。AI 负责生成策略代码，系统负责把策略放进回测流程，最后用历史数据检查策略表现。

> 风险提示：回测不是预测未来。回测只能说明策略在某段历史行情里表现如何，不能保证实盘盈利。带杠杆、加仓、合约交易的策略风险更高，必须先看最大回撤、连续亏损、手续费、滑点和爆仓风险。

## 1. 先把策略参数写完整

不要一上来就让 AI 写代码。先把下面这些参数填清楚，参数越明确，AI 生成的策略越容易编译、回测和复盘。

```text
交易品种：BTC-USDT-SWAP
K线周期：15m
方向：多空都做
布林带参数：20周期，2倍标准差

开多逻辑：
收盘价从下往上突破布林带中轨，开多。

开空逻辑：
收盘价从上往下跌破布林带中轨，开空。

平仓逻辑：
多单跌破中轨平仓；空单突破中轨平仓。

杠杆：5倍
首单金额：100 USDT

加仓方式：
价格反向波动 1% 加仓一次；
每次加仓 100 USDT；
最多加仓 3 次。

止盈止损：
盈利 3% 止盈；
总浮亏 8% 强制平仓；
触发强平后停止继续加仓。

回测范围：
2024-01-01 00:00:00 到 2025-01-01 00:00:00

手续费和滑点：
手续费 0.05%；
滑点 0.03%。
```

如果你还没想好，可以先用这套默认参数跑通流程，再逐步调整。

## 2. 让 AI 生成策略代码

把策略参数整理成下面这种提示词，发送给项目里的 AI 策略生成功能，或者发送给你正在使用的大模型。

```text
请生成一个适合 OKX Trading / Ta4j 回测框架的 Java 策略。

策略名称：BOLL_MID_LEVERAGE_15M
交易品种：BTC-USDT-SWAP
K线周期：15m
布林带参数：周期 20，标准差 2

开多逻辑：
1. 收盘价从下往上突破布林带中轨，开多。
2. 已有多单时不重复开多。

开空逻辑：
1. 收盘价从上往下跌破布林带中轨，开空。
2. 已有空单时不重复开空。

平仓逻辑：
1. 多单跌破布林带中轨平仓。
2. 空单突破布林带中轨平仓。

资金和加仓：
1. 杠杆 5 倍。
2. 首单金额 100 USDT。
3. 价格反向波动 1% 加仓一次。
4. 每次加仓 100 USDT。
5. 最多加仓 3 次。

风控：
1. 盈利 3% 止盈。
2. 总浮亏 8% 强制平仓。
3. 回测时计入手续费 0.05% 和滑点 0.03%。

输出要求：
1. 先解释策略逻辑。
2. 再输出可编译的 Java/Ta4j 策略代码。
3. 标明策略类型 strategyType = BOLL_MID_LEVERAGE_15M。
4. 不要使用未来函数，不要读取未来K线。
```

项目后端启动后，也可以用接口生成策略：

```bash
curl -X POST "http://localhost:8088/api/backtest/ta4j/generate-strategy" \
  -H "Content-Type: application/json" \
  -d '"生成一个 BTC-USDT-SWAP 15m 布林带中轨策略：上穿中轨开多，下穿中轨开空，5倍杠杆，首单100 USDT，反向1%加仓，每次100 USDT，最多3次，盈利3%止盈，总浮亏8%止损，手续费0.05%，滑点0.03%"'
```

## 3. 先检查 AI 代码能不能用

AI 生成代码以后，不要直接相信结果。先检查 4 件事：

- **能不能编译**：类名、包名、Ta4j API、指标名称有没有写错。
- **有没有未来函数**：不能用未来 K 线、未来收盘价、未来最高最低价。
- **交易规则是否和描述一致**：开多、开空、平仓、加仓、止盈止损有没有漏掉。
- **手续费和滑点有没有进入回测**：不计成本的回测通常会虚高。

如果编译失败，把报错继续发给 AI，让它只修复编译错误，不要改交易逻辑。

## 4. 保存策略并确定 strategyType

策略进入回测前，需要有一个稳定的策略标识。建议使用大写英文和下划线：

```text
BOLL_MID_LEVERAGE_15M
```

后面跑回测时，`strategyType` 就填这个名字。

如果你生成了多个版本，可以这样命名：

```text
BOLL_MID_LEVERAGE_15M_V1
BOLL_MID_LEVERAGE_15M_V2
BOLL_MID_LEVERAGE_15M_NO_ADD
BOLL_MID_LEVERAGE_15M_STOP_8
```

这样方便比较不同版本的回测结果。

## 5. 跑一次单策略回测

后端启动后，使用下面这个接口跑回测：

```bash
curl -X POST "http://localhost:8088/api/backtest/ta4j/run?startTime=2024-01-01%2000%3A00%3A00&endTime=2025-01-01%2000%3A00%3A00&initialAmount=10000&symbol=BTC-USDT-SWAP&interval=15m&strategyType=BOLL_MID_LEVERAGE_15M&saveResult=true&feeRatio=0.0005"
```

参数说明：

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `symbol` | `BTC-USDT-SWAP` | 回测交易品种 |
| `interval` | `15m` | K线周期 |
| `strategyType` | `BOLL_MID_LEVERAGE_15M` | 策略标识 |
| `initialAmount` | `10000` | 初始资金 |
| `startTime` | `2024-01-01 00:00:00` | 回测开始时间 |
| `endTime` | `2025-01-01 00:00:00` | 回测结束时间 |
| `feeRatio` | `0.0005` | 手续费比例，0.0005 表示 0.05% |
| `saveResult` | `true` | 是否保存回测结果 |

Windows PowerShell 可以直接用一行：

```powershell
curl.exe -X POST "http://localhost:8088/api/backtest/ta4j/run?startTime=2024-01-01%2000%3A00%3A00&endTime=2025-01-01%2000%3A00%3A00&initialAmount=10000&symbol=BTC-USDT-SWAP&interval=15m&strategyType=BOLL_MID_LEVERAGE_15M&saveResult=true&feeRatio=0.0005"
```

## 6. 看结果时不要只看收益

尤其是带杠杆和加仓的策略，收益高不代表安全。至少要看这些指标：

| 指标 | 为什么重要 |
| --- | --- |
| 总收益 | 看策略在历史区间是否赚钱 |
| 最大回撤 | 看最痛的时候亏了多少 |
| 胜率 | 看交易成功比例，但不能单独使用 |
| 盈亏比 | 看平均盈利是否覆盖平均亏损 |
| 交易次数 | 交易太少可能没有统计意义 |
| 手续费 | 高频策略容易被手续费吃掉 |
| 连续亏损 | 判断心理和资金承受能力 |
| 最大浮亏 | 加仓策略尤其要看这个 |
| 爆仓风险 | 杠杆策略必须重点检查 |

一个比较稳的判断方式：

```text
先看最大回撤和爆仓风险，再看收益。
先看手续费和滑点后是否还赚钱，再看胜率。
先换多个时间段验证，再考虑模拟盘或小资金。
```

## 7. 换时间段做二次验证

不要只跑一个时间段。至少跑三段：

```text
上涨行情：例如 2023-01-01 到 2023-12-31
震荡行情：例如 2024-01-01 到 2024-06-30
下跌行情：例如 2022-01-01 到 2022-12-31
```

如果策略只在某一段表现很好，换个行情就大亏，说明它可能过拟合。

## 8. 常见错误

### 错误 1：AI 写完代码就直接实盘

不要这样做。正确流程是：

```text
生成策略 -> 编译检查 -> 单策略回测 -> 多时间段回测 -> 多币种回测 -> 模拟盘/小资金 -> 实盘监控
```

### 错误 2：只看收益，不看最大回撤

一个策略回测收益 200%，但中间最大回撤 80%，实盘很可能扛不住。

### 错误 3：加仓策略不看爆仓

加仓会把亏损放大。带杠杆时，必须限制最大加仓次数、最大仓位和总浮亏。

### 错误 4：没有计入手续费和滑点

币圈短周期策略交易频繁，手续费和滑点可能吃掉大部分利润。

### 错误 5：把回测当成未来预测

回测不是水晶球。它只能证明策略在过去某段行情中表现如何，不能保证未来继续有效。

## 9. 给新手的最短流程

如果你只想先跑通一次，可以按这个顺序：

```text
1. 填策略参数表
2. 让 AI 生成 Java/Ta4j 策略
3. 编译策略
4. 设置 strategyType
5. 跑单策略回测接口
6. 看最大回撤、手续费、胜率、交易次数
7. 换时间段再跑
8. 结果稳定后再考虑模拟盘或小资金
```

## 11. 评论区可以怎么解释

如果有人问“我会写逻辑，但不会回测”，可以这样回答：

```text
你会写逻辑就够了。先把币种、周期、开仓条件、平仓条件、杠杆、首单金额、加仓方式、止盈止损、手续费和回测区间写清楚。

然后让 AI 生成 Java/Ta4j 策略代码，先编译，再保存 strategyType，最后用回测接口跑历史 K 线。

回测结果不要只看收益，尤其带杠杆和加仓时，要先看最大回撤、连续亏损、手续费、滑点和爆仓风险。
```

## 12. 下一步

跑通单策略后，可以继续做：

- 同一策略跑不同币种
- 同一策略跑不同周期
- 调整布林带周期和标准差
- 去掉加仓版本做对照组
- 固定金额加仓和倍数加仓做对比
- 加入最大仓位限制
- 加入模拟盘或小资金实盘观察

记住：AI 负责提高生成速度，回测负责筛选策略，风控负责让你在实盘里活得更久。
